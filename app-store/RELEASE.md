# Shavit personal helper — release status
26 October 2026 · 2.0 build 3

- Replaces the clothing interface with schedule, workout journal, history, streaks and tasks.
- Native Preferences persistence; browser IndexedDB; private JSON import/export.
- Official Capacitor local daily notifications at 09:00, enabled only after permission.
- Removed IMG.LY background remover and camera/browser plugins; no background-remover licensing dependency in this version.

- Owner enrollment in Apple Developer Program, release signing, current listing/screenshots/privacy answers and App Review submission remain required. This build has not been submitted to the App Store.
- Private exercise histories are not bundled in the site or native app. Import the owner's private JSON file on their device.
